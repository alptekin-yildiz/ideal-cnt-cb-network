# data/reference

Curated ideal-network reference tables behind the paper's figures. The stage
directories hold small summary CSVs you can compare against regenerated
outputs without archiving raw Monte Carlo ensembles. Every table here is
regenerated one-to-one by a `reproduce_paper/` wrapper; derived evidence
tables and provenance metadata live separately in `data/article_evidence/`.

These tables are frozen with the code in the Zenodo snapshot; raw
per-realization data are regenerated deterministically by the seeded wrappers
in `reproduce_paper/`.

| File | What it holds |
|---|---|
| `percolation/cnt_phic_sweep_fixedstep_Lmin50.csv` | CNT length-distribution $\phi_c$ table used by Fig. 4 and to anchor the conductivity / GF sweeps |
| `percolation/cb_phic_sweep_Loverd60_momentmatched_D20_500_n300.csv` | CB aggregate-size $\phi_c$ table used by Fig. 5 and to anchor the conductivity / GF sweeps |
| `percolation/hybrid_phic_boundary_n400_modes.csv` | Hybrid CNT+CB percolation boundary ($\phi_{\rm CNT,c}$ at fixed CB) |
| `percolation/fss_monodisperse_cb_d150.csv` | Finite-size-scaling benchmark, monodisperse CB |
| `percolation/fss_monodisperse_cnt_L500_w_sweep.csv` | Finite-size-scaling benchmark, monodisperse CNT vs waviness |
| `conductivity/simmons_conductivity_regime_n300_m10_Lcb8000_Lcnt4000_Lhyb4000.csv` | Main conductivity loading/scaling summary for CB, CNT, and hybrid systems |
| `conductivity/simmons_conductivity_regime_n300_cnt_high_to_3wt_L4000.csv` | High-CNT extension used by the conductivity loading/scaling figures |
| `conductivity/simmons_conductivity_regime_n300_m17_hybridCB1_Lhyb4000.csv` | Fixed-1 wt.% CB hybrid extension used by the conductivity loading/scaling figures |
| `gf/gf_simmons_gf_affine_cb_40wt_50wt_n300.csv` | Main affine gauge-factor summary for selected CB loadings |
| `gf/gf_simmons_gf_affine_cnt_3wt_n300.csv` | Main affine gauge-factor summary for selected CNT loading |
| `gf/gf_simmons_gf_affine_hybrid_3CNT_1CB_n300.csv` | Main affine gauge-factor summary for the selected hybrid composition |

Column headers are self-describing; thresholds are volume fractions
(`phi_c_vol`) reported with their dispersion across realizations.

The `percolation/`, `conductivity/`, and `gf/` tables double as the inputs
for selected stage-2 wrappers and as compact checks for the paper figures in
`reproduce_paper/`. Per-realization CSVs are not archived here; they are
regenerated by the deterministic wrapper scripts when an exact figure redraw
needs the raw ensemble.

The directory layout is part of the comparison contract: a reference file such
as `percolation/cnt_phic_sweep_fixedstep_Lmin50.csv` or
`gf/gf_simmons_gf_affine_cnt_3wt_n300.csv` is compared against the same
relative path under a regenerated output directory, for example
`data/processed/percolation/cnt_phic_sweep_fixedstep_Lmin50.csv`.

The GF mechanism support package for Fig. 10 and Table 3 is not part of this
directory; it is a derived evidence chain and lives in
`data/article_evidence/gf_mechanism/` with its own README and its own
verification tool.

## Why this is tested

`pytest -q` includes a lightweight integrity test for this directory. The test
does not rerun the long Monte Carlo sweeps; it verifies that the curated
reference set is complete, readable, and still compatible with the comparison
tools. This guards against accidental reference file loss, path changes, or
comparison-tool breakage during maintenance.

After regenerating main paper summaries under `data/processed/`, compare them
with:

```bash
python tools/verify_reference_outputs.py \
    --reference-dir data/reference \
    --generated-dir data/processed
```

`tools/verify_reference_outputs.py` checks the `percolation/`,
`conductivity/`, and `gf/` reference CSVs one-to-one against regenerated
outputs. The derived tables in `data/article_evidence/` are outside this
comparison and are verified by `tools/verify_gf_mechanism_support.py` instead.
